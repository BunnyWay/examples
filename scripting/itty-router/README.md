# itty-router on Bunny Edge Scripting

An [itty-router](https://itty.dev/itty-router) API running as a standalone Edge Script.

## Run locally

```bash
npm install
npm run dev
```

The script runs at http://127.0.0.1:8080.

## Deploy

```bash
bunny scripts create my-itty-router-api --type standalone
npm run deploy
```
