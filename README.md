# bunny.net examples

Small, runnable apps that show how to build with [bunny.net](https://bunny.net). Each product has its own folder.

- [Stream](stream): play video with Bunny Player in React, Next.js, Vue, Nuxt, SvelteKit, Astro, or vanilla JS, upload it over TUS from JavaScript, Laravel, Rails, or Django, and sign embed URLs with token authentication
- [CDN](cdn): serve Next.js and Astro apps through a pull zone from Magic Containers, any host, or Bunny Storage, and resize their images with Bunny Optimizer
- [Sites](sites): deploy a static build from 30 frameworks, from Astro and Next.js to Hugo and Blazor, to Bunny Storage with `bunny sites`
- [Edge Scripting](scripting): run a Hono, Elysia, h3, itty-router, or Express API as a standalone Edge Script, or an MCP server that manages your Edge Scripts with your own API key
- [Storage](storage): upload and manage files over the S3-compatible API with presigned URLs, Uppy multipart, or Bun's S3 client
